# Инструкция по запуску системы контроля шва

## 1. Установка зависимостей

### 1.1. Установка Python 3.8.10

Скачать Python 3.8.10 с официального сайта:
https://www.python.org/downloads/release/python-3810/

При установке отметить галочку "Add Python to PATH".

Проверить установку:
```cmd
python --version
```

### 1.2. Виртуальное окружение

Создать виртуальное окружение:
```cmd
cd C:\proj\python\tvrus
python -m venv venv
```

Активировать окружение (PowerShell):
```powershell
Set-ExecutionPolicy -Scope Process -ExecutionPolicy RemoteSigned
venv\Scripts\Activate.ps1
```

Или через cmd:
```cmd
venv\Scripts\activate
```

В начале строки появится `(venv)`.

### 1.3. Установка библиотек

В активированном окружении выполнить:
```cmd
pip install -r requirements.txt
```

Деактивация окружения:
```cmd
deactivate
```

### 1.3. Установка MVS SDK (для камеры Hikrobot)

1. Скачать MVS 5.x с сайта Hikrobot
2. Установить MVS (включая драйверы камеры)
3. Подключить камеру по Ethernet
4. Проверить обнаружение камеры в клиенте MVS

## 2. Настройка оборудования

### 2.1. Камера Hikrobot

- IP камеры: 192.168.1.36
- Подключение: GigE Vision (Ethernet)
- Убедиться, что ПК и камера в одной подсети

### 2.2. Тестовый стенд (ОВЕН МК210)

- IP контроллера: 192.168.1.99
- Порт Modbus: 502
- Убедиться, что контроллер включён и доступен

### 2.3. Схема подключений ОВЕН

**Входы (DI):**

| DI | Назначение |
|----|------------|
| DI0 | Датчик Д1 (вход конвейера) |
| DI1 | Датчик Д2 (под камерой левый) |
| DI2 | Датчик Д3 (под камерой правый) |
| DI3 | Датчик Д4 (выход конвейера) |
| DI4 | Тумблер (положение A — старт) |
| DI5 | Тумблер (положение B — конец) |
| DI6 | Датчик Д6 (захват / сценарий B) |

**Выходы (DO):**

| DO | Назначение |
|----|------------|
| DO0 | Конвейер (пуск/стоп) |
| DO1 | Толкатель брака (резерв) |
| DO2 | Лампа NG (красная) |
| DO3 | Лампа OK (зелёная) |

### 2.4. Проверка сети

```cmd
ping 192.168.1.36
ping 192.168.1.99
```

## 3.5. Алгоритм распознавания шва (подробно)

Подробное описание алгоритма см. в файле `ALGORITHM_DESCRIPTION.md`.

Кратко, обработка одного кадра состоит из следующих этапов:

1. **Кадрирование по ROI** — обрезка кадра по зоне интереса (настраивается в GUI или config.json).
2. **Конвертация в серый** — перевод цветного кадра в одноканальное изображение.
3. **Проверка контраста** — стандартное отклонение яркости и разница процентилей 5/95. Если контраст слишком низкий, кадр считается пустым (ошибка `ERR_NO_SEAM`).
4. **CLAHE + GaussianBlur** — адаптивное повышение контраста (clipLimit=2.5, чтобы не пересвечивать блик) и подавление шума.
5. **Бинаризация** — инверсная пороговая обработка (Otsu по умолчанию или фиксированный порог). Тёмный шов на светлом фоне становится белым.
6. **Маски игнорирования** — закрашивание бликов, отверстий и иных артефактов (прямоугольные зоны, размечаемые в эталонах).
7. **Авто-маска центрального паза** — сквозное отверстие автоматически маскируется по порогу яркости (`hole_threshold`), чтобы не мешать измерению.
8. **MORPH_CLOSE** — морфологическое замыкание ядром 3×3 для замыкания мелких разрывов внутри шва.
9. **Заливка дырок от блика** — внутренние полости (чёрные дыры внутри белого контура от продольного блика) закрашиваются обратно.
10. **Осевая линия шва (centerline)** — либо загружается из размеченного эталона (равномерно интерполированная полилиния с шагом `step_px`), либо строится автоматически методом `cv2.fitLine` по наибольшему контуру.
11. **Поперечные секущие срезы** — для каждого узла оси строится сглаженная нормаль; вдоль неё ищутся белые отрезки (runs), склеиваются разделённые бликом, и выбирается лучший по коридору/скорингу — это ширина шва в данной точке.
12. **Медианная фильтрация ширин** — одиночные выбросы соседних срезов сглаживаются медианой (окно 3) перед агрегацией.
13. **Пересчёт в миллиметры** — `width_mm = width_px / px_per_mm` (требуется предварительная калибровка).
14. **Агрегация метрик** — средняя/мин/макс ширина, `fill_ratio` (доля неразрывных срезов), `max_gap_mm` (максимальная длина разрыва), 90-й перцентиль смещения центра шва от оси.
15. **Критерии брака**:
    - `ERR_GAP` — разрыв длиннее `max_allowed_gap_mm` или `fill_ratio < min_fill_ratio`;
    - `ERR_WID` — ширина вне `[min_width_mm, max_width_mm]`;
    - `ERR_POS` — 90-й перцентиль смещения шва от оси больше `pos_tolerance_mm`;
    - `ERR_NO_SEAM` — шов не найден или контраст слишком низкий.
16. **Вердикт** — `OK` если нет ошибок, иначе `NOK` с расшифровкой сработавших критериев.

## 4. Запуск

### 4.1. Графический интерфейс (рекомендуется)

```cmd
cd C:\proj\python\tvrus
venv\Scripts\activate
python gui.py
```

Альтернатива:
```cmd
python main.py --gui
```

В окне программы:
- **▶ Старт** — запуск цикла контроля (камера, ПЛК, измерение);
- **⏹ Стоп** — остановка: конвейер выключается, выходы DO сбрасываются;
- **ROI-зона** — выделение зоны сканирования мышью прямо на кадре;
- **Настройки** — режим связи, IP/unit камер и ПЛК, калибровка, границы ширины;
- **Камера** — живое изображение с результатом измерения;
- **Результат** — крупный OK/NOK, ширина шва, счётчики;
- **Журнал событий** — статусы цикла и ошибки.

Для работы GUI необходим Tkinter (входит в стандартную поставку Python).

### 4.2. Консольный запуск

```cmd
cd C:\proj\python\tvrus
venv\Scripts\activate
python main.py
```

Для ROI-режима (выделение зоны сканирования):
```cmd
python main.py --roi
```

При запуске программа:
1. Подключается к камере Hikrobot (Modbus 192.168.1.36:502)
2. Подключается к ОВЕН МК210 (Modbus 192.168.1.99:502)
3. Сбрасывает все выходы (DO0-DO3 = 0)
4. Ожидает DI04 (Тумблер A — старт)
5. Ожидает DI06 (Датчик Д6 — захват)
6. Отправляет триггер камере через Modbus
7. Камера сохраняет фото в папку `data/images/`
8. Программа читает последнее фото и обрабатывает:
   - Обрезка по ROI (зона интереса)
   - Конвертация в оттенки серого
   - Проверка контраста (защита от пустого кадра / отсутствия мастики)
   - CLAHE (повышение локального контраста, clipLimit=2.5) + GaussianBlur (шумоподавление)
   - Бинаризация (Otsu или фиксированный порог, инверсная)
   - Наложение масок игнорирования (блики, отверстия)
   - Авто-маска сквозного центрального паза
   - Морфологическое замыкание (MORPH_CLOSE, 3×3)
   - Заливка внутренних дырок от блика в контуре шва
   - Построение осевой линии шва (равномерно интерполированная разметка эталона или автоматический fitLine)
   - Поперечные секущие срезы (сглаженные нормали к оси) с шагом step_px
   - Измерение ширины белого участка в каждом срезе: runs → склейка split-от блика → лучший run по коридору/скорингу (в мм через px_per_mm)
   - Медианная фильтрация ширин (окно 3)
   - Детекция разрывов, проверка fill_ratio, 90-го перцентиля смещения шва от оси

9. Ширина в мм: `width_mm = width_px / px_per_mm` (средняя по всем неразрывным срезам после медианной фильтрации)
10. OK если:
    - ширина в диапазоне [min_width_mm, max_width_mm],
    - нет разрывов длиннее max_allowed_gap_mm,
    - fill_ratio ≥ min_fill_ratio,
    - 90-й перцентиль смещения шва от оси ≤ pos_tolerance_mm.
11. Отправка результата: DO3 (зелёная — OK) или DO2 (красная — NOK).
12. Ожидание DI05 (Тумблер B — конец цикла)
13. Сброс всех DO, возврат к шагу 4

### 4.3. Остановка

- **GUI**: нажать кнопку `⏹ Стоп` (конвейер останавливается, выходы сбрасываются).
- **Консоль**: нажать `Ctrl+C` в командной строке.

## 6. Калибровка

### 6.1. Определение px_per_mm

1. Сфотографировать объект известного размера (линейку)
2. Измерить ширину объекта в пикселях (OpenCV)
3. Вычислить: `px_per_mm = пиксели / миллиметры`

### 6.2. Настройка порога

Параметр `threshold` в config.json определяет чувствительность бинаризации:
- Меньше значение = больше деталей (но больше шума)
- Больше значение = меньше деталей (но чище изображение)

## 7. Добавление PROFINET

Для работы с KUKA KR200 через PROFINET:

1. Установить драйверы Hilscher cifX
2. Создать `communication/profinet.py`
3. Изменить `config.json`:
   ```json
   "communication": {
       "mode": "profinet",
       "profinet": {
           "device_name": "cifX0"
       }
   }
   ```

## 10. Устранение неполадок

### Камера не определяется

- Проверить IP-адрес камеры
- Убедиться, что MVS установлен
- Проверить брандмауэр Windows

### Modbus не подключается

- Проверить IP контроллера
- Убедиться, что порт 502 открыт
- Проверить настройки Modbus в контроллере

### Ошибки в логах

Проверить файл `app.log` для диагностики.
