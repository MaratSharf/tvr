# Инструкция по подготовке и запуску проекта на промышленном ПК

## 1. Целевая конфигурация

- Операционная система: Windows 7 Ultimate x64 SP1
- Python: 3.8.10
- Папка проекта на промышленном ПК: `D:\tvrus`
- Установка библиотек выполняется офлайн, из локальной папки `wheels`.

> Команды ниже предназначены для командной строки Windows (CMD), а не PowerShell.

## 2. Подготовка файлов

Скопируйте на промышленный ПК папку проекта `tvrus`, включая исходный код, папку `wheels` с файлами `.whl` и файл `requirements-install.txt`, если он используется.

Проверьте, что файлы находятся в `D:\tvrus`.

Основные ожидаемые установочные файлы:

| Компонент | Требуемый файл |
|---|---|
| NumPy | `numpy-1.24.3-cp38-cp38-win_amd64.whl` |
| OpenCV | `opencv_python-4.8.1.78-cp37-abi3-win_amd64.whl` |
| PyModbus | `pymodbus-2.5.3-py2.py3-none-any.whl` |
| PyInstaller | `pyinstaller-5.13.2-py3-none-win_amd64.whl` |
| six | `six-1.17.0-py2.py3-none-any.whl` |
| packaging | `packaging-23.2-py3-none-any.whl` |
| pefile | `pefile-2024.8.26-py3-none-any.whl` |
| altgraph | `altgraph-0.17.5-py2.py3-none-any.whl` |
| pywin32-ctypes | `pywin32_ctypes-0.2.3-py3-none-any.whl` |
| setuptools | `setuptools-69.5.1-py3-none-any.whl` |

Наличие файлов не гарантирует совместимость всех зависимостей с Windows 7. Если установка завершится ошибкой, сохраните полный текст сообщения.

## 3. Открытие командной строки и активация окружения

Откройте меню «Пуск», введите `cmd` и запустите командную строку. Затем выполните:

```bat
cd /d D:\tvrus
venv\Scripts\activate
```

Если виртуальное окружение ещё не создано, создайте его и активируйте:

```bat
py -m venv venv
venv\Scripts\activate
```

Проверьте версию Python:

```bat
py --version
python --version
```

Ожидается Python 3.8.10. После активации окружения команда `python` должна указывать на Python внутри `venv`.

## 4. Установка библиотек без интернета

Выполните в активированном окружении:

```bat
python -m pip install --no-index --find-links=.\wheels numpy==1.24.3 opencv-python==4.8.1.78 pymodbus==2.5.3 PyInstaller==5.13.2
```

`--no-index` запрещает обращение к онлайн-индексу пакетов. `--find-links=.\wheels` указывает искать установочные файлы в локальной папке.

Если установка остановится из-за отсутствующей зависимости, не скачивайте случайную новую версию. Сохраните полный вывод ошибки и добавьте в `wheels` совместимую версию отсутствующего пакета.

## 5. Проверка установленных библиотек

Выполните:

```bat
python -c "import cv2, numpy, pymodbus; print('OpenCV:', cv2.__version__); print('NumPy:', numpy.__version__); print('PyModbus:', pymodbus.__version__)"
```

Ожидаемые версии:

- OpenCV: `4.8.1`
- NumPy: `1.24.3`
- PyModbus: `2.5.3`

Проверьте PyInstaller отдельно:

```bat
python -m PyInstaller --version
```

Ожидается версия `5.13.2`.

## 6. Запуск проекта

При активированном виртуальном окружении выполните:

```bat
python main.py
```

Если требуется графический интерфейс (рекомендуется для эксплуатации):

```bat
python gui.py
```

Либо:

```bat
python main.py --gui
```

Команда предполагает, что точка входа проекта называется `main.py`. Если проект использует другой стартовый файл или специальные параметры, используйте фактическую команду запуска.

## 7. Если возникла ошибка

1. Скопируйте полный текст ошибки, включая строки `ERROR` и `Traceback`.
2. Зафиксируйте команду, после которой возникла ошибка.
3. Проверьте используемый Python:

```bat
where python
python --version
```

4. Проверьте содержимое папки с пакетами:

```bat
dir wheels
```

Не используйте для целевой установки пакеты для Python 3.10, например `numpy-...-cp310-...whl`, или более новые версии основных библиотек без предварительной проверки совместимости.

## 8. Важное замечание

Эта инструкция описывает установку и первичную проверку окружения. Успешная установка библиотек сама по себе не подтверждает работоспособность камеры, оборудования, PLC/PROFINET, драйверов или всех функций проекта. Их нужно проверить отдельно на промышленном ПК.
1. Скопируйте файл

Перенесите файл

pyserial-3.5-py2.py3-none-any.whl

с компьютера разработчика в папку D:\tvrus\wheels на промышленном ПК.

2. Повторите установку на промышленном ПК

В CMD выполните:

cd /d D:\tvrus
py -m pip install --no-index --find-links=.\wheels numpy==1.24.3 opencv-python==4.8.1.78 pymodbus==2.5.3 PyInstaller==5.13.2

Дождитесь окончания установки. Если появится новая ошибка об отсутствующей зависимости, пришлите её текст.

3. Проверьте результат

Если установка завершится успешно, выполните:

py -c "import cv2, numpy, pymodbus; print('OpenCV:', cv2.__version__); print('NumPy:', numpy.__version__); print('PyModbus:', pymodbus.__version__)"

Пришлите вывод этой команды. После проверки перейдём к запуску проекта main.py.
